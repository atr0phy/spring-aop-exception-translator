```
}

{

}
```

## 使用例

```markdown
## 基本情報

### API概要
- **機能名**: ユーザー削除
- **HTTPメソッド**: DELETE
- **エンドポイント**: DELETE /users/{userId}
- **概要説明**: 指定されたIDのユーザーを削除する

### リクエスト仕様
```
パスパラメータ:
- userId: String (必須) - 削除対象のユーザーID
```

### レスポンス仕様
```
成功時 (204 No Content): レスポンスボディなし

エラー時 (404 Not Found):
{
  "message": "ユーザーが見つかりません",
  "code": "USER_NOT_FOUND"
}
```

## ビジネスロジック

### 処理フロー
1. パスパラメータからuserIdを取得
2. userIdの形式をバリデーション
3. ユーザーの存在確認
4. ユーザーを削除
5. 成功レスポンスを返却

### バリデーションルール
- userIdは有効なUUID形式であること

### エラーケース
- **ユーザー不存在**: 404エラーを返却
- **無効なUUID**: 400エラーを返却
```

## 簡易版テンプレート

時間がない場合は、以下の簡易版も使用可能です：

```markdown
**API**: [HTTPメソッド] [エンドポイント]
**機能**: [何をするか]
**入力**: [パラメータやボディ]
**出力**: [レスポンス]
**処理**: [簡単な処理フロー]
```

例:
```markdown
**API**: DELETE /users/{userId}
**機能**: ユーザー削除
**入力**: userId (パスパラメータ)
**出力**: 成功時204、エラー時404
**処理**: 1)存在確認 2)削除実行 3)レスポンス返却
```

## ファイルの配置場所

テンプレートを埋めたら、以下に保存してください：

```
docs/api-requests/{HTTPメソッド}-{リソース名}-{操作名}.md
```

例:
- `docs/api-requests/DELETE-users-delete.md`
- `docs/api-requests/PUT-users-update.md` 
- `docs/api-requests/POST-orders-create.md`

詳細は [docs/api-requests/README.md](api-requests/README.md) を参照。
