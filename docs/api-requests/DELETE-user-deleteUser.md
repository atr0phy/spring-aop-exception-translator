## 基本情報

### API概要
- **機能名**: ユーザー削除
- **HTTPメソッド**: DELETE
- **エンドポイント**: DELETE /users/{userId}
- **概要説明**: ユーザーを削除するAPI

### リクエスト仕様
```
パスパラメータ:
- userId: String (必須) - 削除対象のユーザーID

クエリパラメータ: (該当する場合)
- なし

リクエストボディ: (該当する場合)
- なし
```

### レスポンス仕様
```
成功時 (200 OK): UserResponse

エラー時 (404 Not Found):
{
  "message": "ユーザーが見つかりません",
  "code": "USER_NOT_FOUND"
}
```

## ビジネスロジック

### 処理フロー
1. ユーザーを検索して、排他ロックで取得する
2. ユーザーを削除する
3. 取得した削除したユーザーのデータを返す

### バリデーションルール
- なし

### エラーケース
- **ケース1**: ユーザーが存在しなかった場合は例外を投げる
